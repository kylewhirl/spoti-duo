# Rail control sizing fixture

Build with `sh harness/rail-controls/build.sh` from the repository root.
This reduced UIKit fixture checks Back and More sizing, navigation, taps and short-window behavior.
Use an explicitly selected simulator, never a physical phone. The app logs `ENTITY MENU CHECKS`.

Run with `sh harness/rail-controls/run.sh YOUR_BOOTED_SIMULATOR_UDID`.
